# [Microsoft Ignite 2026](https://ignite.microsoft.com)

## 🔥LAB680: AI Agents Are Sending Signals. Make Access Respond.
### Session description

AI agents need access to corporate resources to be useful, but risk can change what that access should allow. Identity teams, put your policy plans into practice: scale Conditional Access across humans and AI agents, use agent risk to drive access decisions, and adapt enforcement in real time.

### 🚀 Getting started

#### In a guided session (75 minutes total: 15 min intro, 55 min hands-on, 5 min wrap-up)

If you're following along during a live Microsoft Ignite lab session:

1. Launch your lab environment via [LabOnDemand Profile 224816](https://labondemand.com/LabProfile/224816).
2. Sign in to the [Microsoft Entra admin center](https://entra.microsoft.com) using your lab tenant credentials.
3. Open the step-by-step instructions in [`instructions/README.md`](instructions/README.md).

#### On your own

If you're learning at your own pace:

1. Clone this repository
2. Ensure you have access to a Microsoft Entra ID tenant with Microsoft Agent 365, Microsoft Entra Suite, or Microsoft 365 E7 licensing.
3. Follow the self-paced walkthrough in [`instructions/README.md`](instructions/README.md).

### 🎯 Learning outcomes

By the end of this session, you will be able to:

- **Manage Conditional Access policies at scale:** Create Policy Plans with shared conditions and exclusions, separate access rules, and migrate existing policies into a plan.
- **Assess Dynamic Agent Risk:** Review an agent's risk, state, exposure, blast radius, and supporting evidence in Microsoft Entra and compare it with the agent's Dynamic risk assessment in Microsoft Defender.
- **Protect and adapt agent access:** Create report-only rules to block high-risk agent identities and assistive agents, and use the **Restrict Actions** session control for protected actions.
